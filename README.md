# Install

```
git clone
cd tsRestApi
npm install
```

# Build using webpack

```
npm run build
```

# Run

## using ts-node-dev

```
npm run ts-node-dev
```

## using webpack bundle.js

```
npm run node
```


# Test

```
curl localhost:7000/products
```
